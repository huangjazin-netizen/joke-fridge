## The line

> My fridge's vegetable drawer is where good intentions go to rot.

## How it works

`main.py` writes the line above to `entry.txt` in the output folder
(`$MAKEFUN_OUTPUT_DIR`, or `out/` when unset). Run it with Python 3:

```sh
python3 main.py
```

The output is deterministic: the same line, byte for byte, on every run.
